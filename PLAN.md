# Pocket Star — Plan

## Problem
You have an old computer you want to use as a personal server (file storage, local AI inference), but your ISP doesn't provide a public IP. Renting a VPS/VDS with similar specs is too expensive.

## Solution
Rent a cheap VPS/VDS to get a public IP. Set up a site-to-site VPN (star topology) with the VPS as the hub. Your server and workstation connect to the hub, creating an improvised local network. You can then access your server via a "local" VPN IP.

## Architecture

```
VPS (Hub)          Old PC (Server)      Laptop (Client)
10.0.0.1 ───────── 10.0.0.2             10.0.0.3
    │                     │                    │
    ├─ AmneziaWG ─────────┼────────────────────┘
    │   Docker Compose    │ Docker Compose      Native WG GUI
    │                     │                     or pstar CLI
```

## Technology Stack

| Component | Choice |
|-----------|--------|
| Language | **Go** (single binary, cross-compilation) |
| VPN | **AmneziaWG** (obfuscation + WG-compatible conf) |
| Deployment | **Docker Compose** for hub and server; client uses CLI or native WG client |
| CLI | Single `pstar` command |
| Modules | Interface-based; core module in MVP |
| Security | **Master password** (AES-GCM) protecting node configs |

## CLI Commands

| Command | Description |
|---------|-------------|
| `pstar hub init [--docker] [--pass]` | Init VPS as hub (generate configs, keys, docker-compose) |
| `pstar hub status` | List connected peers |
| `pstar node join <hub> [--docker]` | Connect a node (auto via CLI) |
| `pstar node status` | VPN connection status |
| `pstar module list` | List available/enabled modules |
| `pstar module enable <name>` | Enable a module |
| `pstar module disable <name>` | Disable a module |
| `pstar decrypt <file>` | Decrypt an encrypted config |
| `pstar doctor` | System diagnostics |
| `pstar version` | Print version |

## Module System

```go
type Module interface {
    Name() string
    Priority() int
    Dependencies() []string
    Init(*Context) error
    Start() error
    Stop() error
    Status() Status
}
```

MVP: only `core` module (VPN + routing + SSH).

## Security

- WireGuard uses Curve25519 keys (not passwords) — cryptographically secure
- Node configs are encrypted with **master password** (AES-256-GCM)
- Hub config is not encrypted (runs on VPS)
- User can either:
  1. Run `pstar node join` (prompts for master password)
  2. Copy `.enc` file and decrypt manually with `pstar decrypt`

## Docker

Two images:
- `pstar/hub` — hub with AmneziaWG + peer management
- `pstar/node` — node (AmneziaWG client)
- Both require `NET_ADMIN`, `SYS_MODULE` capabilities
- docker-compose.yml generated by `pstar hub init --docker` and `pstar node join --docker`

## User Flow

1. Install `pstar` (curl → script)
2. On VPS: `pstar hub init --docker && docker compose up -d`
3. On server: `pstar node join --hub 1.2.3.4 --docker && docker compose up -d`
4. On laptop: `pstar node join --hub 1.2.3.4` **or** import `.conf` in WG GUI
5. Result: `ping 10.0.0.2 && ssh user@10.0.0.2`
